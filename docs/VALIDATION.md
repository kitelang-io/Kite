## Verdict

Fledge is genuinely in the state the docs' headline claims describe: it self-compiles and self-links native macOS/arm64 Mach-O executables with no `clang`/`as`/`ld`, and the resulting binaries carry a pure-OCaml ad-hoc code signature that the system `codesign -v` accepts and the OS loader runs. A clean `dune build` is warning-free, all six known-good exit codes reproduce exactly (via both `run` and direct execution of the emitted `.out`), the encoder matches `clang` byte-for-byte modulo the intentional `bl`-reloc path, and the four stage-1 Kite programs are correct on edge cases, not merely exit-code-matching. The front end (Pratt precedence, ATI newlines, interpolation, full when/pattern grammar, generics, lambdas) is solid and round-trips through the printer. What is at risk is narrow but real: one **blocker** in frame-slot addressing that silently miscompiles functions with more than 32 locals — directly threatening the stage-1 self-hosting compiler whose functions will exceed that — plus a cluster of tool-robustness and cross-component drift issues (out-of-range int crash, `check`/codegen builtin-table divergence, non-assemblable `asm` text) and several documentation overclaims. None of the intentional stage-0 hacks (boxed aggregates, heap leaks) are treated as defects.

## What is verified working

- **Clean build**: `rm -rf _build && dune build` exits 0 with zero warnings or errors.
- **All 6 known-good exit codes** reproduce exactly, via `run` and via direct execution of the self-linked binary: `examples/native_demo`=24, `examples/native_loops`=67, `stage1/lex`=9, `stage1/calc`=26, `stage1/calcast`=26, `stage1/tokenize`=13. stdout also matches (calc prints 20/14/51; tokenize prints count1=13 count2=13).
- **Genuine self-linking**: `file` reports `Mach-O 64-bit executable arm64`; `codesign -v` passes; `codesign -dv` shows `flags=0x2(adhoc)`, embedded CodeDirectory v=20400. No external toolchain is invoked — the only `Sys.command` (bin/main.ml:156) merely runs the produced binary to read its exit code.
- **obj/exe/asm/lex all function**: `obj` writes a valid Mach-O object (`file` → `Mach-O 64-bit object arm64`, valid Mach header); `exe` self-links a signed executable that runs and passes `codesign -v`.
- **Encoder cross-checked vs clang**: `__text` bytes are byte-identical to `clang -c -arch arm64` of the compiler's own `asm`, except at intra-image `bl` sites (object emits `0x94000000` + `ARM64_RELOC_BRANCH26`; both valid).
- **dyld chained fixups correct**: `dyld_info -fixups/-imports` on `stage1/calc.out` binds `_strlen/_malloc/_snprintf/_printf` in `__DATA_CONST/__got`.
- **Backend semantics correct**: arithmetic/division/mod (incl. large-immediate `movz/movk` chunking and `Sdiv+Msub`), `cset` condition inversion, boxed struct field access, enum variant construction, positional payload binding, and when/pattern-match dispatch (exit 64 = 3+4+50+7). Frame addressing correct through slot 32.
- **Front end**: Pratt precedence/associativity, ATI newline handling (with its documented binary-op-continuation limitation failing gracefully), `$name`/`${expr}`/nested interpolation, triple-quoted raw strings, char escapes, full when/pattern grammar, turbofish + nested generics (`>>>`), lambdas/trailing lambdas, named args, and every declaration form parse and round-trip. All 13 example/stage1 files parse and `check` without crashing.
- **Semantics**: lexical scoping (for/lambda/when-subject/pattern/block), cross-arm pattern isolation, forward/mutual top-level references, and undeclared-lvalue detection are correct; all targeted type-error true-positives fire; valid programs pass with no false positives.
- **Stage-1 programs are truly correct**: calc/calcast left-associativity (`2-3-4`=-5, `10/2/5`=1), integer division (`20/6`=3), deep nesting, full precedence, and agreement between the two evaluators; tokenize handles empty input, keyword-prefix identifiers, greedy 2-char operators (incl. `===` split), digit/ident boundaries, and single-char operator fallback with no out-of-bounds.

## Consistency

Documentation carries the only cross-cutting drift, all documentation-side (no runtime bug behind them):

- **README.md:8-10** overclaims that the system `ld` links the output — flatly contradicted by the code (no `ld` invoked) and by ROADMAP's "ld dropped / fully self-links." This is the most misleading, since self-linking is the project's headline capability.
- **LANGUAGE-DESIGN.md:420** stales the already-DONE own Mach-O emitter/linker into an M8 "not in bootstrap" item.
- **ROADMAP.md:69,71** leaves M2/M4 checkboxes unchecked while its own prose (and the working CLI) mark them DONE.
- **README.md:34 / ROADMAP.md:142** show `for i in a..b`, which does not parse (parens required).

Two implementation-internal inconsistencies also amount to component drift: the resolver's builtin table vs. codegen's actual builtins (major, table above), and the `asm` printer's register-31 rendering vs. the explicit invariant comment at codegen_arm64.ml:62-65 (major, table above). The intentional stage-0 boxed model and heap leaks are by-design and correctly not documented as defects.

## Recommended next fixes

1. **Fix the >32-frame-slot blocker** (codegen_arm64.ml:218-219) — at minimum fail loudly on an out-of-range fp offset; properly, spill deep locals through a scratch base register. This is the only correctness bug that can silently produce wrong binaries and it directly blocks the stage-1 self-hosting compiler.
2. **Reconcile the resolver builtin table with codegen** (resolve.ml:18-24) so `check` stops rejecting KNOWN-GOOD programs; share one builtins list to prevent future drift.
3. **Guard read_number against out-of-range literals** (lexer.ml:107) so the tool degrades to a graceful `Lex_error` instead of aborting.
4. **Correct README.md:8-10** to describe self-linking accurately (and sweep the smaller doc fixes: for-loop parens, M2/M4 checkboxes, LANGUAGE-DESIGN M8 row) while touching the docs.
5. **Fix the `asm` register-31 printing** (print_instr) so the advertised human-readable output assembles and the lines 62-65 invariant holds.
